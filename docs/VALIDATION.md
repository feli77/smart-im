本次精简后在 Windows 11、Python 3.12.11 运行完整自动化测试：**170 passed in 3.95s**，无跳过。Ruff 检查与格式检查、依赖锁文件检查均通过；wheel 和源码包构建成功。运行依赖仅 NumPy，开发依赖为 pytest、Ruff 与 Lupa。

## 自动化范围

- 外部候选排序：索引排列、重复候选、原始顺序、模型上下文增益及异常回退。
- 信箱协议与服务：消息边界、旧请求淘汰、会话隔离、单实例、事件去重、重试、过期清理与退出清理。
- Lua 适配：真实 Lua 5.4 执行，模拟 Rime 候选、通知和上下文，验证 Tab、候选范围、版本、元数据、模式切换和确认事件。
- 跨模块：Lua → 文件 → Python Engine → 文件 → Lua，覆盖双学习开关、模型失败、服务停止和长期停留后的重试。
- 安装与 CLI：现有配置保留、冲突预检、备份、重复安装，以及当前命令入口。
- 模型与个人数据：自带权重加载和评分、离线运行、确认后学习、关闭学习时不读取个人证据、统计查询与清空。本次未重新训练权重。

```sh
uv sync --extra dev
uv run pytest -q
uv run ruff check .
uv run ruff format --check .
uv build
```

已在隔离环境安装 wheel，仅安装 Smart IM 和 NumPy，确认不存在 PySide6、pypinyin、llama-cpp-python 或 pytest。使用临时 Rime 用户目录完成 `install-rime`、`rerank`、`stats`，以及信箱请求 → 服务轮询 → 响应 → 关闭清理的冒烟验证；未修改实际小狼毫配置。

输入候选“实时、事实、实施”和上下文“我们计划”，CLI 返回 `[2, 0, 1]`，信箱返回对应的一基排列 `3,1,2`。默认未创建个人数据库，服务关闭后信箱仅保留锁文件。

发行包包含 schema、Lua、语料和权重，只有 `smart-im` 一个命令入口；源码包保留模型训练脚本。已移除模块、演示词典和历史截图／基准数据均不进入发行包。上述检查不覆盖小狼毫前端部署或真实应用上屏。
