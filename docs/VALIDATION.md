# MVP 验证记录

验证日期：2026-09-30。环境：Linux x86_64，Python 3.12.3；自带 NumPy 小模型。Windows 真机与真实 GGUF 权重尚未验证。

## 自动化覆盖

- 拼音：全拼、简拼、音节分隔、声调与 ü、组合词、单步拼写容错、输入长度和非法字符。
- 排序和学习：真实模型的同音上下文区别、词表外词的分词证据、重复选择改序、新词和多音字持久化、私人表达预测。
- 隐私：学习默认关闭，private 请求不访问个人词库；仅提交时写入；短上下文上限；删除与数据库权限。
- 模型：真实权重载入、离线运行、评分及预测、训练重现；可选 GGUF 的路径/缺依赖/模拟后端接口与 token 预算。
- Qt：真实后台引擎，拼音选词、快速连打空格、Emoji 后选区替换、光标移动取消组合输入、长文纠错偏移、窗口生命周期。
- Windows：结构体 ABI 与 Unicode 代理对、注入过滤、按键按下/释放配对、模式关闭直通、焦点变化、同窗口鼠标变化取消过期提交。使用模拟 Win32 API，不能替代真机上屏验证。

执行：`QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q`，最终结果 **127 passed in 5.34s**。测试文件自行配置 offscreen，Windows 直接 `python -m pytest -q` 即可。

Ruff 检查与格式校验通过。wheel 和源码包构建成功，wheel 内含词典、语料和 `.npz` 权重；在独立环境安装 wheel 后运行 `smart-im suggest nihao`，首选为“你好”。

## 延迟测量

完整数据见 [benchmark.json](benchmark.json)，复现命令：

```sh
python scripts/benchmark.py --output docs/benchmark.json
```

| 项目 | 样本数 | p50 | p95 | 最大值 |
|---|---:|---:|---:|---:|
| 首轮组合查询 | 100 | 0.241 ms | 0.870 ms | 1.549 ms |
| 重复组合查询 | 1,000 | 0.243 ms | 0.766 ms | 6.901 ms |
| 上下文短语预测 | 100 | 0.012 ms | 0.241 ms | 1.569 ms |

引擎初始化 30.930 ms，不含 Python 进程启动和模块导入。基准采用脚本中固定的 10 种拼音和 10 种上下文，学习关闭；重复查询可能命中缓存。预测样本包含无建议的上下文。数值只说明该有限测试负载的引擎开销，不代表中文准确率、最坏延迟或真实 Windows 端到端延迟。

桌面输入使用 25 ms 防抖和后台推理，故界面完整响应时间还应计入防抖、线程调度、布局与上屏。可选 GGUF 不在这些数字内。
