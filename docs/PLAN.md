# MVP 实现计划

> 本文为 v0.1 初始实现记录。当前工作依据 [Rime 最小重构计划](REFACTOR_PLAN.md)。

截至 2026-09-30，以下六阶段的 MVP 代码与文档已交付，127 项自动测试通过。Windows 系统接入代码已实现；真机端到端验收仍待执行。具体测量与限制见 [验证记录](VALIDATION.md)。

| 阶段 | 交付 | 验证 |
|---|---|---|
| 1. 契约与骨架 | 数据类型、架构、依赖、统一 CLI | 可安装、导入 |
| 2. 拼音基础 | 全拼/简拼/组合候选/拼写容错 | 歧义、分隔符、部分输入、长输入边界 |
| 3. 本地智能 | 微型模型、候选排序、短语预测、纠错 | 上下文影响排序、模型实测、无网络依赖 |
| 4. 个人学习 | SQLite 词频与上下文统计、开关、清空 | 重启保留、排序改善、隐私模式不读写 |
| 5. 桌面与 Windows | 编辑体验台、快捷键浮窗、Unicode 上屏 | Qt 无头交互、状态机测试、Windows 真机待验收 |
| 6. 交付 | 锁定依赖、测试、基准脚本、启动说明 | 完整测试、构建、测量与已知局限 |

后续：Windows TSF 原生服务 → 独立本地推理进程与取消协议 → 大词库/标准拼音评测 → GGUF 量化模型硬件评测 → Personal Language Model 个体适配。

## 首版人工验收

1. 输入 `nihao`、`zhongguo`、`jintiankaishi`；数字选词、空格首选、Esc 取消、退格继续编辑。
2. 同一拼音在不同上下文下检查候选排序，并确认所有上屏都需要明确按键或点击。
3. 开启学习，多次选择低频候选，重启后观察个性化提升；关闭学习后不读取或增加个人记录。
4. 检查下一短语能通过 Tab 或点击插入光标处；过期推理结果不得覆盖当前组合输入。
5. 对常见错词显示纠错建议，点击后仅替换对应文本。
6. 断网启动，完成以上流程；不需要 API key。
7. Windows 在记事本等普通权限编辑器验证启停快捷键、窗口切换、中文/英文切换和退出钩子清理。密码输入和管理员应用不作为 MVP 支持场景。
